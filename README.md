# haya — Premium Footwear Concept

A polished React + Vite landing page concept for a premium footwear brand, built with Tailwind CSS, Framer Motion, and Lenis.

## What was refined

- Preserved the original visual direction, product imagery, motion, and editorial layout.
- Removed fabricated press mentions, customer reviews, audience counts, addresses, and performance/sustainability statistics.
- Reframed the page as an explicit product/design concept so the visual story can be showcased without presenting invented commercial proof as real.
- Reworked the final CTA so it no longer simulates a newsletter signup without a backend.
- Replaced dead `#` social/footer links with real in-page navigation.
- Improved consistency between hero, collection, pricing, FAQ, and footer copy.
- Kept reduced-motion behavior and smooth scrolling intact.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Note

The product names, prices, material systems, and visual specifications are part of the fictional concept. Replace them with verified product information before using the site for real commerce or public product claims.
